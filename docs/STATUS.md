## What works right now

- EPUB and PDF import: SHA-256 identity, metadata, covers, duplicate detection.
  Engine entry: `apps/reader` uses `packages/engine` (`importBook` in
  `packages/engine/src/import.ts`); reader engine is the pinned foliate-js
  submodule at `vendor/foliate-js` (commit `78914ae`, MIT).
- Library: search with Persian yeh/kaf normalization
  (`apps/reader/src/library/bookList.ts`), sort, grid/list views,
  `content-visibility` for large libraries.
- Reader: paginated/scrolled EPUB modes, TOC, font size, light/sepia/dark
  themes, justification, direction-aware keys, resume. Key component:
  `apps/reader/src/components/ReaderView.tsx`.
- Annotations: selection popover (5 colors + note draft), notes panel
  (jump/edit/delete/tombstones), Markdown/JSON export, in-book search with
  excerpt highlighting. Uses foliate-js `addAnnotation`/`draw-annotation`
  (`Overlayer.highlight`), notes in `apps/reader/src/stores/notesStore.ts`.
- Persistence: **SQLite is authoritative**. Desktop: rusqlite bundled, opened
  in `setup`, commands `db_execute`/`db_execute_batch`/`db_select` in
  `apps/reader/src-tauri/src/lib.rs`. Web: sql.js + OPFS with debounced flush
  (`apps/reader/src/services/sqlStorage.ts`). Shared schema/repositories in
  `packages/storage/src/sql.ts`; repositories map rows in `sql.ts`.
  The Phase 1 JSON manifest (`library.json` + `books/<sha256>.<ext>` +
  `covers/<sha256>`) is imported once (`json_migrated` marker in `meta`) and
  kept as a debounced backup. Blob files still live in `DataStorePort`
  (`packages/platform`) — Tauri app-data commands / OPFS. Persist calls:
  `apps/reader/src/services/libraryPersistence.ts`.
- Desktop: Tauri v2 shell, product `Hamesh`, id `app.hamesh.reader`; open-with
  via CLI (`initial_book_path`, `read_external_file`) and `.epub`/`.pdf` file
  associations. Linux build/launch verified; Windows CI compiles only.
- PDF: imports, pages in the fixed-layout renderer (`foliate-fxl`), PDF
  open-with. pdf.js assets served from `apps/reader/public/vendor/pdfjs`
  (generated by `scripts/copy-pdfjs.mjs`; Vite transform in
  `apps/reader/vite.config.ts` rewrites `pdfjsPath` because Vite 8 turns the
  upstream dynamic `new URL` into a broken directory glob).

## Key decisions (all in `docs/adr/`)

- Stack: Tauri v2 + React + Vite + TypeScript strict; SQLite desktop,
  sql.js/OPFS web; foliate-js pinned submodule; Biome; Vitest/fast-check;
  Playwright. License MIT. Seven-package workspace with one-way deps
  (`core` ← `platform`/`engine`/`ui` ← `storage` ← `sync`; app is the only
  composition root).
- Sync model: HLC packed `<physicalMs 13hex>-<counter 8hex>-<deviceId>`;
  per-field LWW with `{v,t,s}` envelopes; remove-wins tombstones; tie-break by
  device id; hash-only remote tree `Hamesh/`; no titles in remote filenames;
  schemaVersion + preserve unknown keys; N-provider capable engine, single
  provider in UI at first, mirroring later; no sharding; no relay.
- Phase 1 JSON manifest remains as fallback/backup (ADR-0010).

## Gotchas learned (do not rediscover)

- foliate-js `View` needs **`view.open(book)` then `view.init({lastLocation |
  showTextStart})`** — `open` alone renders nothing.
- `foliate-view` uses a **closed shadow root**; its iframe is still reachable
  via `page.frames()` in Playwright.
- Fixed-layout (PDF) `relocate` has no CFI and `fraction: 0, size: 1`; progress
  comes from `SectionProgress`; page index is in `detail.section.current`.
- Vite 8 turns foliate's dynamic `new URL` into a broken directory glob —
  patched in `vite.config.ts` (`foliatePdfPathFix`), assets copied by
  `scripts/copy-pdfjs.mjs` into `public/vendor/pdfjs` (gitignored, generated).
- TS 7 removed `baseUrl`; use relative `paths`.
- `sql.js` DB flush is debounced (300 ms); `ActiveStorage.flush()` must be
  awaited after book/note writes and on `visibilitychange`.
- rusqlite 0.41 `column_names()` returns an iterator, not a slice.
- Corepack is broken on this machine; pnpm 12 was installed globally.
- `vendor/foliate-js` and `apps/reader/public/vendor` are excluded from Biome.
- Tauri commands use snake_case arg names; JS `invoke` passes plain objects.
- `cp`/`sha256sum`/`unzip`/`sqlite3` CLI are used for tests; `xdotool`/`wmctrl`
  are not installed (screenshots via ImageMagick `import -window root`).
